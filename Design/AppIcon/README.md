The symbol should read immediately at 32 pixels: bold, balanced, distinctive, restrained and modern. Elegant soft dimensional edges and very gentle shadow, no glossy glass clutter, no photographic texture. Only one unified mark, no tiny interface details, no account/avatar badges, no arrows, no text or letters, no wordmark, no surrounding mockup, no watermark.
